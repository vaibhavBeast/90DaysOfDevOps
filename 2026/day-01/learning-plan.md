What is your understanding of DevOps & Cloud?

Cloud - Cloud is like a platform to provide rented services such as storage, virtual machines, servers and many other infra services. Not every company can have their own on premises data center or infrastructure built, that's why cloud platform was needed. So these cloud platforms like AWS, Azure , GCP provide infra from their datacenter to organizations/individuals on pay as go model/pricing basis. So the small organizations can afford having their data stored cost efficiently. Also these cloud providers guarantee data security and data isolation.

Devops - Development + Operations
I am new to Devops, so i have very few idea of what actually is Devops. I will write what i know till now about Devops.

why devops was needed? In the early days, developer used to write code and used create zip of the code and passed to Operations team for deployment. Then the operations team used to deploy code on the servers. If any changes need to be made then again developer will make changes then again he will create a zip file of whole code then again pass to Operations team then they will redeploy the application, downtime will be greater.
Devops made this process easier by developers write code directly and it will get deployed easily without creating zip files hustle, thats called continuous Integration and Continuous deployment.

Devops reduces time to market, provides solutions faster to end user and is scalable.
